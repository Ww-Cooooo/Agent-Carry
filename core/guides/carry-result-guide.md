# 跨模型任务结果回收

只有分级任务完成后由 Level 3 复核时读取。

先读任务包中的 `result/SUMMARY.md` 和 `result/CHANGES.md`；只有结论不足时才打开被引用的少量证据或源文件。不要默认读取完整日志、全部截图或执行过程。

向用户报告：完成结果、偏离计划、尚存风险、需要用户验收的内容，以及 Level 3 在“如何给 Level 1 规划”方面学到的改进。学习内容先形成带真实来源和证据的信号，再按 `core/protocols/ASSET_LIFECYCLE.md` 处理：即使用户刚才已经说要记住，也先集中展示一次精确内容与范围并取得真实选择；用户完成这次选择后不重复确认同一内容。风险分级只能让低风险候选更早进入验证和复核，不能让它自动试用或成为正式资产；中高风险、冲突、实质覆盖和删除还要完整说明后由用户决定。SOP 的成熟度只随能够在验证证据索引中闭合的真实任务结果提升。

验收后清理任务包、日志、截图和缓存；只保留被批准的正式资产。
