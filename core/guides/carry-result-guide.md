# 跨模型任务结果回收

只有分级任务完成后需要回收和复核结果时读取。模型等级用于建议复核强度，不是读取或继续工作的身份门。

先读任务包中的 `result/SUMMARY.md` 和 `result/CHANGES.md`；只有结论不足时才打开被引用的少量证据或源文件。不要默认读取完整日志、全部截图或执行过程。

向用户报告：完成结果、偏离计划、尚存风险、需要用户验收的内容，以及本次在“怎样把任务交代得更清楚”方面学到的改进。学习内容按 `core/protocols/ASSET_LIFECYCLE.md` 处理：即使用户刚才已经说要记住，也先集中展示一次精确内容与范围并取得真实选择；用户完成这次选择后不重复确认同一内容。风险分级只能调整候选复核顺序，不能让它自动试用或成为正式资产；中高风险、冲突、实质覆盖和删除仍由用户决定。SOP 的成熟度只随真实任务结果提升。

验收后只清理当前任务明确拥有且没有恢复价值的临时材料；失败现场、用户资料和其他来源必须保留，除非用户另行授权。
