# 跨模型任务结果回收

只有分级任务完成后由 Level 3 复核时读取。

先读任务包中的 `result/SUMMARY.md` 和 `result/CHANGES.md`；只有结论不足时才打开被引用的少量证据或源文件。不要默认读取完整日志、全部截图或执行过程。

向用户报告：完成结果、偏离计划、尚存风险、需要用户验收的内容，以及 Level 3 在“如何给 Level 1 规划”方面学到的改进。学习内容先形成带真实来源和证据的信号，再按 `core/protocols/ASSET_LIFECYCLE.md` 处理：用户当前已明确授权的内容不重复确认；满足实例低风险学习政策的内容可在通知并提供撤销方式后试用；中高风险、冲突、实质覆盖和删除仍由用户决定。SOP 的成熟度只随真实任务证据提升。

验收后清理任务包、日志、截图和缓存；只保留被批准的正式资产。
