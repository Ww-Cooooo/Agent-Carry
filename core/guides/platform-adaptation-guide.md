# 平台与换机适配

正式资产的语义不随 Agent、模型或操作系统变化。适配时只处理能力差异、路径、工具和展示层。

1. 若当前宿主只是新会话没有回执，先路由到 `host-session-resume`；若首次接入、宿主确已变化或状态无法确认，再路由到 `host-integration`。本指南只处理接入确认后的系统、路径、工具和展示适配。
2. 从已验证接入回执识别当前系统、宿主、可用工具、模型确认方式和文件权限，不把旧宿主档案当作当前事实。
3. 比较实例记录的本地路径；询问用户换机后对应目录是否变化。
4. 不要求不同电脑具有相同任务文件。只迁移用户选择的正式资产和隐私包，各设备可保存不同本地数据。
5. 对平台特有动作生成临时适配或说明；不要在核心中长期维护三套同义脚本。
6. 新平台无法直接支持某项能力时，保持能力语义不变，记录替代工具、限制和验证方式。
7. 检查新宿主能否读取跨会话控制记录和极小唤醒胶囊；只能接收文本时，改用启动胶囊和自然语言回执，不得声称已经直接持久化。
8. 完成后更新一个相关宿主档案和本地环境记录，不扫描全部宿主；若时区变化，比较带偏移量的正式提醒时间并重建时间索引与最早唤醒聚合，但不擅自改变原定时刻。最后更新看板快照，不修改实例方向。

任何联网查平台资料前先加载外部安全边界。
