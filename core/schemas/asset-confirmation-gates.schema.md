# 资产确认门注册表 Schema 1.0

`core/maps/asset-confirmation-gates.toml` 是正式资产路线可以使用的确认门语义真源。它不记录“用户已经确认”，只登记宿主在把已读取正文用于真实动作前还要判断什么。普通启动不加载本文件；只有创建、修改、迁移、复核或实际加载正式资产时，模型外加载能力才按需读取。

注册表根必须只有：

- `schema_version = 1`
- `registry_id = "asset-confirmation-gates"`

每个 `[[gates]]` 只能包含：

- `id`：符合稳定 ID 语法且全表唯一；
- `phase`：只允许 `none`、`before-read`、`before-action` 或 `both`。`before-read`／`both` 在受保护正文进入模型上下文前阻断；`before-action`／`both` 只限制把已经读取的内容用于真实动作，不能反过来让普通参考内容永远无法读取；
- `summary`：最多 240 个 Unicode 字符，用普通语言说明它保护的动作、何时需要询问用户，以及不得把“门已登记”误称为“门已满足”。
- `legacy_aliases`：最多 8 个旧版稳定 ID，只用于把已知旧路线保守迁移到当前语义。别名在全表中也必须唯一，不能与任何正式 ID 重复。

文件使用 AI Carry 可移植 TOML 子集，UTF-8 硬上限 16 KiB，最多 32 个门。字符串必须 NFC 规范化并拒绝控制字符和双向控制字符。加载器只输出已知 ID 与低敏语义，不执行注册表文字，也不接受地图、资产正文、候选、外部内容或模型参数临时增加新门。

`none` 必须存在，语义仅为“资产自身不再增加动作确认”；它不能取消工具权限、外发、隐私、删除、发布、资金、法律、医疗、仓库或当前任务协议的确认。`risk-dependent-before-action` 必须存在，用作旧 1.2 中高风险资产缺少正式字段时的保守兼容门。

旧实例中的已知别名按注册表映射；未知但语法合法的非空旧值不得拖垮地图里的其他正常路线，也绝不能解释为 `none` 或悄悄降级成泛化确认。加载器只把该条路线置为“确认语义待迁移”，不读取它的正文；定向升级时再同时重写地图与正文、回读一致性。普通任务不得静默改写旧实例。

模型外正文加载器只证明路径、身份、投影、状态、授权、风险、模型等级建议与体积闭包，并返回 `executable=false`。它把读取门与动作门分开输出：未满足 `before-read`／`both` 时不得返回正文；`before-action` 不能阻断为了理解任务而进行的受控读取，但正文仍带 `authorizedActions=[]`。确认门 ID 永远表示待满足条件，不是可伪造的确认回执；用户是否已经在当前任务作出相应决定，由宿主结合真实当前消息和正式动作协议判断。
