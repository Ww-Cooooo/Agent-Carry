# AI Carry 2.0.8 → 2.0.9

2.0.9 沿用原来的轻量升级入口。请从看板或当前对话说“检查并升级 AI Carry”，先看只读预览，再单独确认本次升级；不要手工复制产品文件。

本次把官方公开仓库迁到 `Ww-Cooooo/AI-Carry`，旧 `Ww-Cooooo/Agent-Carry` Git 地址继续作为兼容入口；新生成的安装、Release、安全报告和 Pages 地址使用新名称。看板首屏重新组织了产品承诺、唯一主动作、动态核心和随身内容导航，但没有增加新的用户流程、依赖、后台服务或手机端承诺。

升级只替换母版拥有的产品文件并更新产品版本。实例身份、`created_from`、方向、档案、地图、记忆、能力、SOP、经验、验证、候选、治理卡、Skill、组件、专业工作区、本机绑定、私密内容、未来字段和未知文件继续保留；快照根据合并后的真实实例内容重建，不能用空模板快照覆盖实例。

只有固定 `v2.0.9` 标签、正式 Release、公开 `main`、发布清单和完整目标树一致，并且用户明确确认本次升级后，2.0.9 才能替换实例。旧仓库来源仍可识别；一个视觉、WebGL 或快照刷新问题只局部降级并向用户说明，不会让整个助手停止工作。
