# 1.4.3 → 1.4.4 Skill 工坊补丁说明

1.4.4 是正式发布的 Skill 工坊补丁。升级仍必须先在尚不存在的隔离目录中组装和验证；只有官方固定 `v1.4.4` 标签、对应 Release、`release-manifest-1.4.4.toml` 和源码 ZIP 解压树一致，并且用户明确选择升级这个固定版本时，才可替换实例。该固定版本不授权未来的提交、推送、标签、Release 或 Pages。

## 这次新增什么

- 看板提供“Agent 推荐整理的 Skill、已生成的 Skill、已安装 Skill、接入 Skill”四个电脑端页签；推荐只是只读建议，不会自动转换资产。
- 用户明确选择一个正式 SOP 或包含稳定流程的能力后，Agent 才把这一项复制到本地隔离草稿，自动脱敏、通用化和参数化；来源资产不修改，草稿默认不上传、不公开、不分享。
- 已生成 Skill 的详情按钮只复制有界请求。Agent 必须从本地导出索引回读稳定 ID 和真实状态，再继续检查、准备分享预览或解释问题。
- 外来 Skill 先在隔离目录只读检查。检查不执行脚本、不安装依赖、不登录账号，也不会为了通过而自动脱敏、删除或静默改写原包。
- 单个包只会得到 `ready`、`review` 或 `isolated` 的局部结果；Agent Carry、对话和其他 Skill 继续可用。

## 空模板分支

- 从完整 1.4.3 空模板在尚不存在的隔离目录组装目标；
- 模板继续保持 `instance_id=template`、未选择方向、未批准档案，以及 0 项记忆、能力、SOP、经验、候选、验证记录、组件、待办和 Skill；
- 不预创建 `instance/skills/exports/index.toml`，不生成 Skill 包，也不加入演示资产；
- `instance/manifest.toml` 的 `created_from` 与产品版本使用 1.4.4，严格启动胶囊和两份快照从同一清单重新生成；
- 通用和完全虚构的剪辑领域首次创建生命线继续通过；第二次执行同一文件事务不改变任何文件、记录、时间或快照字节。

## 已实例化助手分支

- 冻结完整 1.4.3 来源树、回滚点和切换前当前运行会话的产品版本；
- 原样保留实例身份、`created_from`、方向、档案、交流方式、学习政策、地图、信号、治理排期、宿主、Skill 需求与已安装路由、本地导出索引与生成包、记忆、能力、SOP、经验、验证记录、候选、组件、扩展、工作区、本机绑定、私密引用、用户正文和未知字段；
- 只把实例清单中的产品版本从 1.4.3 更新为 1.4.4，不重新执行首次实例化，不打开工坊，不转换资产，不检查或安装外来 Skill，不刷新未变化的时间，也不制造资产、证据、候选、待办、组件、导出或会话证明；
- 从合并后的严格实例清单重建启动胶囊，再从合并后的正式真源重建 public/dist 双快照并要求逐字节一致；
- 所有保留路径逐路径、逐字节一致且第二次文件执行零变化后，才可进入正式切换判断。

## 会话激活与故障范围

- 切换前会话基线早于 1.4.4 时，状态保持“文件已安装、会话待激活”。默认在同一实例根目录开启一个新任务，正常执行 `BOOTSTRAP.md` 和轻量会话恢复；
- 激活后的代表行为只需证明 Skill 工坊路线能够读取真实空态或现有低敏索引并给出正确引导，不需要为了验收转换真实资产、安装外来包或执行脚本；
- 会话待激活或代表行为失败时，不回滚已经验证有效的新实例；只隔离升级完成结论，普通对话、只读能力和不依赖该行为的功能继续可用；
- 单个 Skill、导出索引或包检查失败时只隔离当前对象并保留原字节。只有目标文件、实例切换、严格启动胶囊或正式快照无效时，才恢复完整 1.4.3 文件事务前像；
- 每次等待、自动修复、重试、局部隔离或回滚都必须用自然语言说明影响、数据状态、仍可用范围和推荐下一步。
