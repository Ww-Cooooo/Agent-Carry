# AI Carry 2.0.7 → 2.0.8

2.0.8 沿用原来的轻量升级入口。请从看板或当前对话说“检查并升级 AI Carry”，先看只读预览，再单独确认本次升级；不要手工复制产品文件。

本次只替换母版拥有的 Skill 工坊指南、动作、开放格式说明、检查器和派生产物。用户选择一个正式方法后，AI Carry 会从当前对话和资产提取已有意图，只追问会改变成品的缺口，自动处理隔离副本，再生成可由不同 Agent 读取的 Skill；不要求安装、更新或依赖某个宿主的 Skill Creator。宿主已有原生 Creator 时可以作为可选复核，缺失或失败只跳过这项增强。

升级不会改写已有 Skill、导出草稿、ZIP、安装副本或登记。旧版顶层共享身份继续兼容；用户以后真正修改那份 Skill 时可以转为标准 metadata，不为了格式单独升级版本。新旧身份冲突只暂停那一份 Skill，AI Carry、对话和其他能力继续可用。

升级必须继续保留实例身份、`created_from`、方向、档案、地图、记忆、能力、SOP、经验、验证、候选、治理卡、Skill、组件、专业工作区、本机绑定、私密内容、未来字段和未知文件。看板快照从保留后的实例真源重建，不能用空模板快照覆盖实例。

只有固定 `v2.0.8` 标签、正式 Release、公开 `main`、发布清单和完整目标树一致，并且用户明确确认本次升级后，2.0.8 才能替换实例。一个可选 Creator、Skill 包或派生刷新失败，只处理那一项；身份、隐私、所有权或正式目标真实冲突时，才暂停当前切换并保留原实例。
