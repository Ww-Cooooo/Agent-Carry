# AI Carry 2.0.6 → 2.0.7

2.0.7 沿用原来的轻量升级入口。请从看板或当前对话说“检查并升级 AI Carry”，先看只读预览，再单独确认本次升级；不要手工复制产品文件。

本次只改变母版拥有的产品与离线看板文件：页面默认展示更短的摘要、状态和主动作，详情与补充解释按需展开；迁移与安全、检查升级、私密导入导出、问题报告和 Skill 工坊入口重新归位。它不增加 Schema、后台服务、自动联网或新的用户确认流程。

升级必须继续保留实例身份、`created_from`、方向、档案、地图、记忆、能力、SOP、经验、验证、候选、治理卡、Skill、组件、专业工作区、本机绑定、私密内容、未来字段和未知文件。看板快照从保留后的实例真源重建，不能用空模板快照覆盖实例。

如果某个派生入口或看板刷新失败，只报告并重试该项；已经有效的核心升级、对话与无关能力继续可用。只有核心身份、隐私、所有权或正式目标发生真实冲突时，才暂停当前切换并保留原实例。

看板正式验收范围仍是 1024px 及以上电脑窗口，不把手机窄屏作为升级成败条件。只有固定 `v2.0.7` 标签、正式 Release、公开 `main`、发布清单和完整目标树一致，并且用户明确确认本次升级后，2.0.7 才能替换实例。
