# 宿主接入档案

这里保存当前实例与不同宿主协作时的极小接入元数据。`registry.toml` 只负责定位一个可能匹配的档案；具体档案在首次接入或用户明确恢复时，根据 `core/templates/integration/blank-host-profile.toml` 创建到 `profiles/`。

注册表不属于固定启动文件。正常新会话只有在短恢复路线命中后才读取极小注册表和一个相关档案；首次接入、换 Agent、当前接入无法确认、用户明确刷新，或实际任务需要重新校验某项宿主能力时，才通过完整协议展开受影响部分。任何路线都不读取全部档案。

允许保存：宿主的用户可理解标签、上次观察环境、接入方式、能力状态、限制、验证时间、宿主协作记忆盘点状态和已迁移资产引用；模型的界面选择标签、当前请求实际模型、路由模式和辅助模型必须分开并带低敏观察依据；宿主原生记忆／长期指令是否自动进入会话只保存状态与类别概况。

禁止保存：系统提示、隐藏规则全文、密码、令牌、Cookie、登录态、授权头、完整进程参数、完整宿主记忆、完整对话、其他用户数据或无关设备信息。宿主能力、模型路由和自动上下文行为可能随版本、配置和权限变化，档案只是“上次确认”，使用时仍按任务需要校验。

轻量注册表默认不超过 8192 字节，单份档案默认不超过 16384 字节。预算在档案／索引变更或恢复失败时顺手检查，不后台轮询；不再适合轻量恢复的条目可以退出注册表，但档案文件不会因此被删除。
