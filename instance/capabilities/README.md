# 可复用能力（实例拥有）

- 格式：Markdown + 前置元数据。
- 模板：`core/templates/capability/blank-capability.md`。

## 怎样找到一项能力

正式小型索引只有 `instance/maps/domain-map.toml` 一份；命中路线后才读取对应正文。本说明不再维护第二张手工表，避免地图、正文和看板出现三份不同状态。

用户不需要知道能力正式名称。先用当前任务结果、对象和日常说法与地图中的少量元数据匹配；命中后才加载能力正文。多个能力都可能适用且会改变做法时，使用用户当前交流语言说明差别让用户选择，而不是展示 ID 或路径。

## 规则

- 能力描述可复用的判断或操作能力，不复制整份 SOP。
- 能力正文是完整的可携带核心；当前宿主的命令、工具和界面方法写入 `experience/host-execution`，仅通过稳定 ID 引用。
- 授权和成熟度分开：用户允许使用不等于已经可靠；成熟度只根据真实独立任务证据更新。
- 使用时先读核心，再从 `host_experience_refs` 按当前宿主筛选最多一个经验；没有经验就动态映射，不扫描全部宿主记录。
- 能力清单看领域地图 `instance/maps/domain-map.toml` 元数据。
- Agent 在真实任务中发现可跨任务复用的判断方法时，主动说明它以后能帮助什么并询问是否留下；用户不负责判断内部应该叫“能力”还是“SOP”。
