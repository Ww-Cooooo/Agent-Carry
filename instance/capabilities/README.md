## 规则

- 能力描述可复用的判断或操作能力，不复制整份 SOP。
- 能力正文是完整的可携带核心；当前宿主的命令、工具和界面方法写入 `experience/host-execution`，仅通过稳定 ID 引用。
- 授权和成熟度分开：用户允许使用不等于已经可靠；成熟度只根据真实独立任务证据更新。
- 使用时先读核心，再从 `host_experience_refs` 按当前宿主筛选最多一个经验；没有经验就动态映射，不扫描全部宿主记录。
- 能力清单看领域地图 `instance/maps/domain-map.toml` 元数据。
