# 实例档案

实例化后在此保存用户批准的方向说明、工作偏好、补充沟通偏好、自动化边界、隐私策略和环境假设。实例当前选择的交流方式、学习政策与隐私处理模式以极小字段保存在 `instance/manifest.toml`；这里只在用户提出更具体的表达习惯、选择更严格边界或确有必要时解释补充偏好，不复制完整风险、安全和成熟度规则。

`profile.guidance_mode` 只决定当前 Agent 解释得多细、怎样追问和以什么节奏协作：`step-by-step` 为一步步引导，`balanced` 为适度引导，`direct` 为直接协作。它不是用户能力等级，也不对应模型 Level；实例化后可以单独调整，不能借此修改已锁定的助手方向或既有资产。

默认边界是：当前用户选择的宿主模型／API可以处理任务所需的最小隐私上下文；额外网站、邮件、MCP／插件、其他 Agent／账号／人员和仓库是新的接收方；Git 始终排除隐私与秘密。API 密钥、密码、令牌、Cookie、私钥和恢复码不是普通隐私，不保存到本目录、不进入模型上下文，也不进入迁移包，应由宿主的凭据机制或用户在目标环境重新配置。

通用实例与领域实例使用相同结构；领域实例增加领域范围和越界反例，通用实例强调跨领域个人协作方式。方向身份的唯一真源仍是 `instance/manifest.toml`。
