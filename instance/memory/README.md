# 长期正式记忆（实例拥有）

- 格式：Markdown + 前置元数据（见 `core/schemas/asset-frontmatter.schema.md`）。
- 模板：`core/templates/memory/blank-memory.md`。
- 真源：Markdown 文件；本地索引/缓存只是派生物。

## 怎样找到一条记忆

正式小型索引只有 `instance/maps/domain-map.toml` 一份；先用低敏元数据命中路线，再按需读取对应正文。本说明不再维护第二张手工表，避免地图、正文和看板出现三份不同状态。

## 规则

- 不存聊天全文、冗长日志或无价值琐事。
- 用户当前明确要求记住、修改或删除时，不重复确认同一内容；仍检查隐私位置、外发和不可逆后果。
- 任务命中后，当前用户选择的宿主模型／API可以取得完成任务所需的最小相关隐私正文；“相关”不授权发送给网站、邮件、MCP／插件、其他 Agent／人员、Git 或公开位置。API 密钥、密码、令牌、Cookie、私钥、恢复码和登录态不得写入记忆或提供给模型。
- 一次模型／宿主推断先成为候选。只有狭窄、可撤销、重复真实验证的低风险内容可以按实例政策通知后试用；身份、隐私、安全、重要偏好和高影响内容必须确认。
- 当前有效内容与按需历史分开；条件不同的偏好保留条件分支，不互相覆盖。
- 低频但关键的内容不因长期未用而清理。
- 同类检索先看小型主题、对象、主张、范围和别名，再读取少量正文；不为合并加载全库。
- 记忆引擎可升级（见 `core/guides/memory-engine-upgrade-guide.md`），Markdown 始终真源。
