# 长期治理模块

本目录存放三个长期改进计划：记忆治理、一致性体系和 Agent 安全。它们不属于普通 TODO，不代表尚有日常任务未完成。

- 平时不加载正文，不后台运行，不建立定时扫描。卡片保存下一建议时间，非启动时间索引保存有界元数据，启动胶囊只保存全部定时事项的最早时间和总数。
- 看板可以只显示名称、上次/下次建议日期和状态。
- 当前时间达到最早唤醒时间时，Agent 只读取时间索引并给聚合提醒；用户选择某项，或主动提出相关新技术并要求研究后，才从维护地图读取对应卡。
- 每轮研究由 Level 3 完成，联网前加载外部内容安全边界；改动正式架构前再次征得用户批准。
- 每轮完成后从实际完成时间重新计算 180 天；公开模板发布前清空维护者日期，新实例在实例化时初始化自己的时间。
