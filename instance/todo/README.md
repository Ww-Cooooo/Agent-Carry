# 普通 TODO

只有用户明确要求加入、查看、执行、更新或删除 TODO 时，才读取本目录中的对应卡。普通任务不加载 TODO 正文；看板只展示有界标题和状态。

- 用户明确说“加入 TODO”才创建；模型等级不足导致的延期任务属于另一套延期系统。
- 每张卡必须详细保存用户原意、背景、已确认决定、禁止猜测项、所需文件、恢复入口和验收/删除条件，使无原对话的 Agent 能完整接手。
- 用户要求执行但未指定哪一项时，可以只展示小型清单并询问先做哪项；选中后只读对应卡。
- 完成后标记 `status = "done"`，看板用删除线和“已完成”展示，不再提供重复处理动作。用户要求从看板移除时，把 `visible = false`；这相当于归档显示，不删除本机正文和完成历史，需要时仍可查询或恢复。用户明确要求彻底删除正式记录时才删除文件。
- 三项长期技术治理不放在这里，位于 `instance/governance/`。
