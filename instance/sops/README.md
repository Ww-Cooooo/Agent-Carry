## 规则

- SOP 是完整的可携带核心，清楚描述目的／非目标、触发／排除、所需资产、输入、四方职责、步骤、分支、能力需求、风险、验证、失败恢复、用户输出和学习更新。
- 网页/软件/硬件变化时先基于语义目标定位，再观察、确认、执行；失败后自我修正并记录偏差候选。
- 宿主专属的命令、按钮、路径和工具映射另写为宿主执行经验，不能取代核心语义。
- SOP 是否允许使用看授权，是否可靠看真实证据成熟度；普通低风险 SOP 在日常任务中渐进验证，不要求企业级回归。
