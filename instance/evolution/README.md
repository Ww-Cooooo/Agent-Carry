# 进化候选与证据记录（实例拥有）

- 格式：Markdown + 前置元数据。
- 模板：`core/templates/evolution/blank-candidate.md`。

## 怎样找到一条进化候选

候选通过 `instance/maps/domain-map.toml` 与极小动态信号按需发现，不在本说明维护第二张手工表；这样不会因为漏改目录 README 而让地图、正文和看板显示不同状态。

## 流程

1. 任务结束先判断这次发现是否值得长期保存；没有长期价值时不生成候选。
2. 命中后只用主题、对象、核心主张、范围、条件、别名和稳定事件 ID 匹配少量同类项，不读取全部记忆正文。
3. 用户当前明确要求记住或批准时，直接按风险和安全边界写入目标资产，不重复确认同一决定。
4. 一次模型／宿主推断先保留为候选。至少两个独立真实成功事件、低风险、无冲突且能通知用户时，可按实例学习政策进入可撤销试用；中高风险仍由用户确认。
5. 拒绝、已合并或无复用价值的低风险候选及时删除／压缩；延期只有在用户要求提醒时才进入时间索引。
6. 资产变化后刷新相关小地图和看板快照；普通启动不读取候选正文。

> 次数只触发检查，不自行产生授权。低风险晋升的授权来自用户已经选择的实例学习政策，并且必须通知、可撤销；身份、隐私、安全、重要偏好和高影响流程不能使用这条捷径。
