# 进化候选与证据记录（实例拥有）

- 格式：Markdown + 前置元数据。
- 模板：`core/templates/evolution/blank-candidate.md`。

## 怎样找到一条进化候选

候选正文不会混进正式资产路线，也不进入普通启动胶囊。当前任务已经出现学习价值、用户点名学习建议，或普通资产路线明确未命中但出现可复用做法时，才沿 `evolution-model -> candidate-index` 读取 `index.toml` 的低敏检索元数据，最多返回 3 条已经获得观察授权的候选；仍无法判断时再读取这些候选的 frontmatter，最后才打开一条经过身份、授权、修订和 32 KiB 物理硬线核验的必要正文。待核对、已撤销和复核项只有用户明确点名稳定 ID 时才返回一条状态投影，不读取正文，也不把整批历史交给模型。

`index.toml` 是可重建投影，不是第二份真源。它必须与候选正文一起作为一个可恢复的多文件动作更新；结构、预算、溢出、清理和故障规则见 `core/schemas/evolution-candidate-index.schema.md`。普通观察、完整证据、聊天原文、秘密和私密资料都不进入索引。

## 流程

1. 任务结束先判断这次发现是否值得长期保存；没有长期价值时不生成候选。询问用户前只保留任务内观察，不写候选、索引、信号或提醒。跨聊天恢复只允许一条有 TTL、无语义正文、不会进入启动或迁移的本机操作回执；它不是候选或资产，也不能自行推进学习。
2. 命中后只用极小候选索引中的主题、对象、核心主张、范围、条件、排除项、别名和稳定事件 ID 匹配少量同类项，不枚举目录或读取全部候选、记忆正文。
3. 用户当前明确要求记住或批准时，仍展示一次与精确内容摘要绑定的预览，让用户选择“留下”；当前通用母版没有模型不可访问的消息角色认证通道，因此普通 JSON、网页、附件、其他 Agent 或模型转述都不能触发免确认直写。用户完成这一次预览选择后，不再机械重复确认同一内容。
4. 一次模型／宿主推断不能静默落盘。用户选择“先观察”时才保留为候选；选择“留下”时，安全闭合的精确预览可以一轮确认直写正式资产。若当前只能交给 Level 3 复核，选项必须提前说清，并建立不可执行交接；只要内容与范围没有实质变化，Level 3 不得重复询问同一保存决定。已启用 `risk-tiered` 的实例可对已获准观察的候选累计极小证据，并让证据充分、低风险、无冲突的候选优先接受复核。授权不等于成熟度，首次观察仍不能冒充成功验证。
5. 拒绝、已合并或无复用价值的低风险候选及时删除／压缩；延期只有在用户要求提醒时才进入时间索引。
6. 候选变化后同步极小候选索引；正式资产变化后刷新相关小地图和看板快照。普通启动不读取候选索引或候选正文。

> 次数只触发检查，不自行产生授权。实例学习政策只决定候选验证和复核的先后顺序；正式资产授权来自用户对具体内容和范围的明确确认，或同一用户主本中可核验的既有明确授权。
