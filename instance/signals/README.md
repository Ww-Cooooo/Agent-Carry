# 跨会话信号状态

本目录保存需要跨任务累计的正式状态卡。它们不是用户的正式记忆正文，也不能绕过资产生命周期和用户确认门。

- `control.toml` 是极小修订和中断恢复记录，启动时与信号地图一起读取。
- 其他 `.toml` 文件每个表示一个真实运行中的信号；从 `core/templates/signal/blank-signal.toml` 创建。建议按 `count/`、`health/`、`state/`、`validity/` 分目录，当前事件只枚举命中的一个类别。
- `instance/maps/signal-map.toml` 是极小唤醒胶囊，只投影临近、待处理、冲突、不确定和恢复路线；普通观察状态留在本目录。
- `instance/maps/time-trigger-map.toml` 是非启动时间索引；日期未到时不得读取。时间真源仍在治理、延期或候选卡的小型字段中。
- 没有真实累计或异常信号时，本目录只保留本说明和控制记录，不创建示例状态卡；控制修订仍可能因治理日程等其他正式触发状态而非零。
- 原始隐私、完整对话、完整外部内容和宿主专用操作步骤不得写入状态卡。

处理、重建或清理时读取 `core/protocols/CROSS_SESSION_SIGNALS.md`；普通任务不扫描本目录，也不读取统一触发注册表。
